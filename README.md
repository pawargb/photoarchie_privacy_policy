# PhotoArchie Privacy Policy

Static, dependency-free privacy-policy page for PhotoArchie. It is intended for GitHub Pages and the App Store Connect Privacy Policy URL field.

## Publish with GitHub Pages

1. Push these files to the repository's `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main`, the repository root (`/`), and **Save**.
5. After GitHub finishes deployment, verify:
   `https://pawargb.github.io/photoarchie_privacy_policy/`

Use the exact public HTTPS URL in App Store Connect. PhotoArchie's Settings and subscription paywall open this page inside the app.

## Maintenance checklist

Review and update the policy, its revision date, and the App Store privacy label before changing any of these practices:

- enabling analytics or crash reporting;
- adding ads or tracking;
- adding accounts, cloud backup, sync, or a developer-operated server;
- changing RevenueCat, feedback, hosting, or other providers;
- uploading photo/video content or metadata off device; or
- changing retention, deletion, or security behavior.

The page intentionally loads no external fonts, scripts, images, analytics, or developer-set cookies.
